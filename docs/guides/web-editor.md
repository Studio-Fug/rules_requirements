# Web editor

A web application for managing the model interactively is in development:
authoring and editing user needs, requirements, risks and mitigations; a live
trace graph; comparing the model across branches and tags; browsing from an
entity to the code annotated with it; and agent-assisted reviews that look for
gaps and record them as notes or new entities.

This page will document it once it lands. Until then, the model files are plain
YAML ({doc}`model`), and the single-object-per-file layout is already the one
the editor will write.
